# AmigaUnicode68k v0.1 — εγγενής απόδοση ελληνικών TTF στην Amiga

Πρώτο αυτοτελές τμήμα του σχεδιαζόμενου browser για AmigaOS 3.x και Motorola 68040/68060. Δεν χρησιμοποιεί διακομιστή ή δεύτερο υπολογιστή **κατά την εκτέλεση**. Η μεταγλώττιση μπορεί να γίνει σε άλλο σύστημα, όπως συμβαίνει με πολλά έργα ανάπτυξης για Amiga.

Το πρόγραμμα φορτώνει γραμματοσειρά TrueType ή OpenType με τη FreeType 2, διαβάζει πραγματικές συμβολοσειρές UTF-8 (μονοτονικά και πολυτονικά ελληνικά, λατινικά και σύμβολα), σχεδιάζει τους χαρακτήρες σε ενδιάμεση επιφάνεια 8 bit και μεταφέρει την εικόνα σε παράθυρο Intuition. Το παράθυρο εμφανίζεται στην οθόνη Workbench είτε αυτή χρησιμοποιεί AGA είτε RTG. Στην απλή αρχική υλοποίηση, οι βαθμίδες του γκρι αντιστοιχίζονται σε έως πέντε pens του Workbench. Η τεχνική είναι σωστή για δοκιμές, αλλά η σχεδίαση πολλών διαδοχικών `RectFill()` δεν είναι η τελική λύση απόδοσης.

## Τι έχει ελεγχθεί

Η ρουτίνα αποκωδικοποίησης UTF-8 έχει μεταγλωττιστεί και περάσει έξι ελέγχους σε υπολογιστή ανάπτυξης: ελληνικά, πολυτονικά, τετρα-byte χαρακτήρες και εσφαλμένες ακολουθίες UTF-8. **Δεν έχει γίνει ακόμη μεταγλώττιση 68k ούτε εκτέλεση του προγράμματος σε WinUAE ή φυσική Amiga.** Στο παρόν περιβάλλον δεν υπάρχει μεταγλωττιστής Amiga 68k ούτε τα αρχεία ανάπτυξης FreeType για δοκιμή της πλήρους μηχανής απόδοσης. Ο πηγαίος κώδικας είναι αφετηρία προς μεταγλώττιση, όχι έτοιμο και δοκιμασμένο εκτελέσιμο.

## Μεταγλώττιση

Χρησιμοποίησε την αλυσίδα μεταγλώττισης του έργου [AmigaPorts/m68k-amigaos-gcc](https://github.com/AmigaPorts/m68k-amigaos-gcc). Ο επίσημος Makefile περιλαμβάνει στόχο μεταγλώττισης της FreeType για το σύστημα-στόχο.

Στον κατάλογο της αλυσίδας μεταγλώττισης:

```sh
make all -j$(nproc)
make libfreetype2
make zlib
```

Οι βιβλιοθήκες πρέπει να έχουν μεταγλωττιστεί για την ίδια επιλογή CPU και βιβλιοθήκης C με το πρόγραμμα. Αφού προσθέσεις το `m68k-amigaos-gcc` στο PATH, μέσα στον κατάλογο του παραδείγματος:

```sh
make amiga                  # αρχικός στόχος 68040 + FPU
make amiga CPU=68060       # επιλογή 68060, εφόσον υπάρχει συμβατή FreeType
```

Το παραγόμενο αρχείο θα ονομάζεται `AmigaUnicode68k`. Αν η δική σου στατική FreeType χρειάζεται πρόσθετες βιβλιοθήκες, τροποποίησε το `FREETYPE_LIBS` στον Makefile. Η συγκεκριμένη ρύθμιση δεν έχει επαληθευτεί με πραγματικό 68k linker.

Για να επαναλάβεις τις ήδη επιτυχημένες δοκιμές του αποκωδικοποιητή UTF-8, αρκεί κοινός μεταγλωττιστής C:

```sh
make selftest
```

Η προαιρετική εφαρμογή δοκιμών σε Linux (`make host`) χρειάζεται εγκατεστημένα `libfreetype-dev` και `pkg-config` και παράγει εικόνα PGM από την ίδια μηχανή rasterization. Δεν έχει μεταγλωττιστεί στο παρόν περιβάλλον λόγω έλλειψης των αντίστοιχων αρχείων ανάπτυξης.

## Εκτέλεση στην Amiga

Με AmigaOS 3.x, 68040/68060 με FPU και Fast RAM, τοποθέτησε το εκτελέσιμο σε έναν κατάλογο και πρόσθεσε δίπλα του μια υποδιαδρομή `Fonts/` που θα περιέχει την ελληνική γραμματοσειρά `DejaVuSans.ttf` ή άλλη με αντίστοιχη κάλυψη Unicode. Το αρχείο γραμματοσειράς δεν περιλαμβάνεται στο πακέτο.

Από AmigaShell:

```
AmigaUnicode68k "PROGDIR:Fonts/DejaVuSans.ttf"
```

Στο παράθυρο, `B` εκτελεί οκτώ επαναλήψεις απόδοσης, `R` σχεδιάζει ξανά το κείμενο και `Q` κλείνει το πρόγραμμα. Στο Shell εμφανίζονται η κατανάλωση Fast RAM, οι χαρακτήρες που αποδόθηκαν, οι χαρακτήρες που λείπουν από τη γραμματοσειρά και οι χρόνοι απόδοσης/μεταφοράς στο παράθυρο. Ο χρονισμός γίνεται με `timer.device` και `ReadEClock()`.

Τα **64 MB Fast RAM** αποτελούν τον ελάχιστο σχεδιαστικό στόχο για τον μελλοντικό browser, όχι απαίτηση που ελέγχει αυτό το μικρό δοκιμαστικό πρόγραμμα. Το ίδιο ισχύει για τη MMU: ο σχεδιασμός προβλέπει αξιοποίησή της, αλλά η εικονική μνήμη δεν έχει ακόμη υλοποιηθεί. Η σωστή σύνθεση αποσυντεθειμένων Unicode χαρακτήρων (βάση + συνδυαζόμενος τόνος) θα απαιτήσει μεταγενέστερη ενσωμάτωση μηχανής shaping, όπως η HarfBuzz. Η παρούσα δοκιμή αφορά κυρίως προσυντεθειμένους χαρακτήρες.

## Περιεχόμενα

- `src/utf8.c`, `src/utf8.h`: αυστηρός αποκωδικοποιητής UTF-8.
- `src/font_core.c`, `src/font_core.h`: FreeType, μετρικές, kerning, ενδιάμεση επιφάνεια γραφικών.
- `src/amiga_main.c`: παράθυρο AmigaOS, απεικόνιση RastPort, ανάγνωση Fast RAM, χρονισμοί.
- `src/host_main.c`: βοηθητική έκδοση ελέγχου σε Linux.
- `tests/test_utf8.c`: αυτόνομοι έλεγχοι χαρακτήρων.
- `Makefile`: μεταγλώττιση για Amiga, δοκιμή UTF-8 και βοηθητική μεταγλώττιση σε Linux.
